# Arun Saini — Portfolio

A lightweight, responsive portfolio for a backend-focused Senior Software Engineer working with Elixir/Phoenix, Ruby on Rails, and PostgreSQL.

## Contents

- Professional positioning and capabilities
- Three anonymized production case studies
- Experience and technology summary
- Email and LinkedIn contact links

## Run locally

No build tools or dependencies are required.

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

Opening `index.html` directly also works, but a local server more closely matches deployment behavior.

## Deploy with GitHub Pages

1. Create a public GitHub repository.
2. Push the contents of this directory to the repository's default branch.
3. Open **Settings → Pages** in GitHub.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then save.
6. Add the generated URL to LinkedIn and the GitHub repository description.
